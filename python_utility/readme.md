## 📂 Utility Folder – Python Mini Projects

This folder contains a collection of **daily Python utility mini-projects** built to strengthen core programming concepts through hands-on practice.
Each script focuses on solving a small real-world problem using clean logic, user input, and standard Python libraries.

---

* Basic output styling
